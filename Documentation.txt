[KRITIS] 2.1 Tidak Ada Security Headers
─────────────────────────────────────────
File: vercel.json
Masalah:
  - Tidak ada Content-Security-Policy (CSP)
  - Tidak ada Strict-Transport-Security (HSTS)
  - Tidak ada X-Frame-Options (rentan clickjacking)
  - Tidak ada X-Content-Type-Options
  - Tidak ada Referrer-Policy
  - Tidak ada Permissions-Policy

Dampak: Website rentan terhadap XSS injection, clickjacking, MIME sniffing,
        dan tidak memaksa koneksi HTTPS.

Rekomendasi: Tambahkan headers di vercel.json:
  {
    "headers": [
      {
        "source": "/(.*)",
        "headers": [
          { "key": "X-Frame-Options", "value": "DENY" },
          { "key": "X-Content-Type-Options", "value": "nosniff" },
          { "key": "Strict-Transport-Security", "value": "max-age=31536000; includeSubDomains" },
          { "key": "Referrer-Policy", "value": "strict-origin-when-cross-origin" },
          { "key": "Permissions-Policy", "value": "camera=(), microphone=(), geolocation=()" },
          { "key": "Content-Security-Policy", "value": "default-src 'self'; img-src 'self' https://www.daffiq.love; font-src 'self' https://fonts.gstatic.com; style-src 'self' 'unsafe-inline' https://fonts.googleapis.com;" }
        ]
      }
    ]
  }

[TINGGI] 3.1 Google Fonts Blocking Render
──────────────────────────────────────────
File: root.tsx
Masalah:
  - Font dimuat via <link href="...fonts.googleapis.com..."> di <head>
  - Tidak ada font-display: swap pada URL
  - Tidak ada preload untuk font files
  - Menyebabkan FOIT (Flash of Invisible Text) saat loading

Rekomendasi:
  - Tambahkan &display=swap pada URL Google Fonts
  - Atau lebih baik: self-host font files untuk mengurangi external dependency
  - Tambahkan <link rel="preload"> untuk font files kritis

[TINGGI] 3.2 Gambar Tidak Dioptimasi
──────────────────────────────────────
File: Semua komponen yang menggunakan <img>
Masalah:
  - Tidak ada lazy loading (loading="lazy")
  - Tidak ada srcset/sizes untuk responsive images
  - Format JPEG tanpa alternatif WebP/AVIF
  - Tidak ada width/height eksplisit (menyebabkan layout shift / CLS tinggi)
  - Gambar dimuat dari external domain (latency tambahan)

Rekomendasi:
  - Tambahkan loading="lazy" pada gambar di bawah fold
  - Tambahkan width dan height attribute untuk mencegah CLS
  - Konversi ke WebP dengan JPEG fallback
  - Gunakan gambar lokal dari /public/image/

[TINGGI] 4.1 Inkonsistensi TypeScript vs JavaScript
─────────────────────────────────────────────────────
Masalah:
  - tsconfig.json dikonfigurasi dengan strict: true
  - Konfigurasi file (.ts/.tsx): root.tsx, routes.ts, vite.config.ts
  - Komponen SEMUA menggunakan .jsx (bukan .tsx)
  - Tidak ada type annotations di komponen manapun

Dampak: TypeScript strict mode tidak memberikan manfaat karena komponen
        tidak menggunakan TypeScript. Type safety hilang.

Rekomendasi:
  - Migrasi semua komponen dari .jsx ke .tsx
  - Tambahkan interface/type untuk props, state, dan data
  - Atau jika memang tidak mau pakai TS, hapus tsconfig strict mode

Website ATMA memiliki fondasi visual dan UX yang BAIK — design system konsisten,
animasi smooth, dan responsive. Namun dari sisi engineering, terdapat gap
signifikan terutama di area:

1. KEAMANAN: Tidak ada security headers sama sekali. Ini adalah kelemahan
   paling kritis yang harus segera ditangani.

2. RELIABILITAS: Ketergantungan pada domain eksternal (daffiq.love) untuk
   semua aset visual adalah single point of failure yang berbahaya.

3. KONSISTENSI: Proyek dikonfigurasi untuk TypeScript strict tapi semua
   komponen ditulis dalam JavaScript biasa — ini menunjukkan setup yang
   tidak dimanfaatkan dengan benar.

4. PERFORMA: Font blocking dan gambar tanpa optimasi akan berdampak pada
   Core Web Vitals (LCP, CLS) yang mempengaruhi SEO dan user experience.

Untuk mencapai standar "professional-grade", fokus utama harus pada security
headers, asset management (lokal), dan konsistensi codebase.
